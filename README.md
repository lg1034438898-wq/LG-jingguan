# 景观 AI 结果评价体系

## 项目概述

基于 80 条真实交互数据和 100 道标准测试集，构建景观 RAG 系统的 AI 结果评价体系。包含检索质量评估、生成质量评估和 Power BI 质量监控看板三大模块。

## 核心交付物

### 1. 100 道《景观 AI 标准测试集》

覆盖图纸规范、智能配植、方案文本、效果图咨询四大类，每道题标注标准答案和难度等级。

### 2. 检索质量评估报告

- 混合检索 Recall@5 = 91%
- MRR = 0.658
- 智能配植类别表现最优（Recall = 96%）
- 核心洞察：混合检索不是银弹，知识库覆盖度是根本瓶颈

### 3. Power BI 质量监控看板

- 4 张 KPI 卡片 + 5 张核心图表
- 智能配植采纳率预警（60%）
- 长沙地区采纳率偏低（58%）

## 关键发现

| 发现 | 数据证据 | 优化建议 |
|------|----------|----------|
| 智能配植三重警报 | 使用 37.5%、采纳 60%、耗时 4.97s | Rerank 精排 + 元数据过滤 |
| 长沙采纳率偏低 | 58.3% vs 杭州 90% | 补充地域气候标签 |
| 知识库覆盖盲区 | 9 道未命中题中 5 道缺数据 | 补充适老化/儿童活动区资料 |

## 技术栈

Python / Pandas / Power BI / MySQL / ChromaDB / BGE-M3 / BGE-Reranker

## 项目结构

- `eval/`：检索质量评估脚本与数据
- `AIchaxun.csv`：80 条真实交互数据
- `100 道《景观 AI 标准测试集》.xlsx`：标准测试集
- `app.py` / `build_database.py` / `chunk.py` / `fenliu.py`：RAG 系统核心代码

## 使用方法

1. 运行 `python test_set_builder.py` 生成测试集
2. 运行 `python auto_fill_and_evaluate.py` 跑评估
3. 打开 Power BI 看板查看可视化
